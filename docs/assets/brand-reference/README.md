# Brand reference

Put the 91 Degree menu image(s) here: photo, scan or PDF of the menu board.

The owner decided (Q-06) that the logo should be **taken from the menu**. During step P7 the logo is cropped (or traced to SVG) from these images and saved as `apps/web/public/brand/logo.svg` / `logo.png`. It is not redesigned. Colours in `docs/DESIGN_SYSTEM.md` are checked against the same images.

Until an image is here, the app uses the typographic brand mark ("91° DEGREE").
