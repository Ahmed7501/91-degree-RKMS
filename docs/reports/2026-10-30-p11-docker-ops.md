# Report — P11 Docker images, production Compose and operations scripts
Date: 2026-10-30 (Asia/Karachi) · Phase/step: Phase 2, P11 · Author: Claude Code

## 1. Summary
The production packaging is built and has been proven with a **prod-like local run** of the real images:
- **Images:** a multi-stage server image (Node 24.18 bookworm-slim, non-root, Prisma CLI included for migrations) and a web image (nginx-unprivileged 1.29.3).
- **Web nginx:** serves the SPA, sets the CSP and security headers, and proxies `/api` and `/socket.io` with WebSocket upgrade. It uses the Docker DNS resolver, so a recreated `server` container never causes stale-IP errors.
- **Production Compose file:**
  - Services: `db`, a one-off `migrate`, `server`, `web`.
  - No host ports, hardened containers (memory limits, log rotation, `no-new-privileges`, read-only root filesystems with dropped capabilities for the app containers), and an explicitly named volume.
- **Proxy overlays:** Traefik labels on the existing network (A), or a loopback port behind host nginx/Caddy (B).
- **Database role:** a production init script creates the non-superuser `rkds_app` as the database owner.
- **Operations scripts:** `lib/compose.sh` (the single compose command), `backup.sh` (verified file dumps, 7-day retention that always keeps the newest 3), `verify-backup.sh` (scratch-database drill), `restore.sh` (confirmation flag, safety dump first, single transaction) and `vps-inspect.sh` (read-only VPS inventory).
- **G8 check:** `scripts/compose-check.mjs` validates both overlays and the dev file.
- **Browser coverage:** the `@smoke` end-to-end subset now also runs on Firefox and WebKit.

## 5. Remaining limitations / open items
- **Not run on the VPS:** live deployment, the real proxy, HTTPS/HSTS and the backup cron are all NOT RUN. They need a domain, VPS access and the owner's approval (DEPLOYMENT §2–7).
- **Duplicate headers on API responses:** they get both nginx's and helmet's security headers. The values are compatible: the CSP intersection only affects JSON responses.
- **Script permissions:** `scripts/*.sh` are LF-terminated (via `.gitattributes`). The executable bit must be set when committing (`git update-index --chmod=+x`), or the scripts run with `bash scripts/…`, as the docs show.
- **Logs:** `vite preview` prints harmless `ECONNRESET` lines when test browser contexts close their sockets.
- **Footprint:** measured on Docker Desktop (Windows). It needs re-measuring on the VPS.
