## 5. Remaining limitations / open items
- **Changes from the planning docs (docs updated):**
  - **Session index:** now the plain index `(role, revoked_at)`. A partial index would show up as Prisma drift.
  - **Audit-event id:** `order_events.id` is a BIGSERIAL. Prisma doesn't model identity columns.
  - **Shadow database:** dev migrations use a `rkds_shadow` database owned by `rkds_app` (`SHADOW_DATABASE_URL`) instead of the superuser URL (`DATABASE_ADMIN_URL`, removed).
- **Prisma 7.10.1 quirk:** `prisma migrate diff` silently prints nothing and exits 0 when no datasource is configured. This is documented in DATABASE §5. The drift check always sets the datasource, and its negative control proves it works.
- **npm 11 approvals:** npm blocks package install scripts by default. `prisma` and `@prisma/engines` were approved explicitly (`allowScripts` in `package.json`), because Prisma needs its migration engine.
- **No destructive Prisma commands:** following the prisma-cli skill's safety rule, nothing destructive was run (no `migrate reset`). The test harness recreates only the guarded `_test` schema with plain SQL.
